# ECE-8893-FPGA---Final-Project
This repository contains the code for our final project for the course Parallel Programming for FPGA

# Neuro-Symbolic Kernel Optimization for Cognitive AI Systems

This project explores the optimization of neuro-symbolic AI kernels on FPGA hardware, focusing on latency reduction and resource efficiency. We implement and analyze two key components: a neural kernel (ResNet18 layer) for feature extraction and a symbolic kernel (circular convolution) for spatial-temporal reasoning.

# Folders
neural/ - contains the data and code related to neural kernels

symbolic/ - contains the data and code related to symbolic kernels
